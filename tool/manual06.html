概要とライセンス・動作条件

本カスタマイズコードは、WordPress公式ブロックテーマ「Twenty Twenty-Five」上で、ポートフォリオ（ギャラリー）機能および小説テキスト投稿機能を実装するためのコードです。

注意: 本コードの内容を編集すると WordPressの編集画面にログインできなくなる といったエラーが発生する危険性があります。コードの知識がない方はコードの内容を編集せず、導入手順通りにコピペするだけにしてください。

動作前提条件

  • WordPressバージョン: 6.0 以上推奨 (検証: 7.1.3)
  • 対応テーマ: Twenty Twenty-Five (検証: 1.5)
  • 推奨サーバー環境: PHP 7.4 / 8.0 以上 (検証: 8.5.x)

このカスタマイズコードの主な機能

1. WordPressのGUIツールに対応

  • ノーコードで編集: ファイルを指定した場所にアップロード（もしくはコードを追記）したあとは、WordPressの編集画面から簡単に編集できます。
  • 選べる5種類のテーマカラー: 編集画面から選択するだけでテーマカラーを変更できます。カラーは「グレー」「ブルー」「ピンク」「グリーン」「パープル」から選択可能。
  • レスポンシブ対応: PC、タブレット、スマートフォンなど、観覧環境に合わせたレイアウトでページを表示。

2. 快適な作品展示

  • セクションの増減: セクション（コンテンツのブロック）を必要に応じて増減できます。
  • カテゴリーごとに表示: セクションにカテゴリー（スラッグ）を設定することで、作品をカテゴリーごとに展示することができます。
  • 「もっと見る」機能: 最新の投稿を一覧の上側に表示し、ボタンタップで段階的に追加読み込みします。1度に表示する件数も選択できます。

3. Gallery（イラストギャラリー）

  • サムネイル自動取得: 記事内の画像を自動に取得し、サムネイルにしてトップページに表示します。
  • モーダル拡大表示: 画像タップでふわっと拡大。タイトルと画像は中央、説明文は左寄せで綺麗に表示。

4. Novel（小説・テキスト投稿）

  • 冒頭の自動プレビュー: 本文の冒頭を抜粋して一覧に表示します。注意事項などを冒頭に書くことで、リンクを開く前に伝達できます。
  • フォントを明朝体に（single.html 適用時）: 小説ページに明朝体を適用し、文章を美しく見せます。

導入手順（詳しいガイド）

STEP 1

投稿カテゴリーを作成する

WordPress管理画面の 「投稿」＞「カテゴリー」 で以下の2つを作成します。

• イラスト用 ➔ 名前: イラスト / スラッグ: illust
• 小説用 ➔ 名前: 小説 / スラッグ: novel

※カテゴリー名やスラッグは一例です。イラスト（小説）のみをサイトに展示する場合は片方だけ作成すれば大丈夫です。

STEP 2

ファイルをテーマフォルダ内に配置する

サーバーのファイルマネージャーまたはFTPソフトを使い、front-page.php を以下の通り配置します。② ③ のコードは既存のファイル（functions.php および single.html）の末尾にコピペしてください。

// ① トップページ用ファイル（新規作成配置）
/wp-content/themes/twentytwentyfive/front-page.php
// ② 編集用コード（functions.php の末尾に追記）
/wp-content/themes/twentytwentyfive/functions.php
// ③ 小説ページ用コード（single.html の末尾に追記）
/wp-content/themes/twentytwentyfive/templates/single.html

※小説ページ用コードは必要な場合のみ使用してください。小説ページのデザインを整えるだけなので、使用しなくてもページは表示されます。

STEP 3

トップページを編集する

  1. 管理画面の 「外観」＞「カスタマイズ」＞「トップページ設定」 を選択。
  2. セクション名、補足テキスト、表示件数などをお好みに編集し、「公開」ボタンで確定します。
STEP 4

表示確認とトラブルシューティング

サイトトップを開き、表示を確認します。変更が反映されない場合は以下を確認してください。

💡 エディターのカスタマイズリセット: 過去に「外観」から「個別投稿」のデザインを編集したことがある場合、そちらの設定が優先されるため、single.html のデザインが反映されません。「外観 ＞ エディター ＞ テンプレート ＞ 個別投稿」の右上メニューから「カスタマイズをリセット」を実行し、設定を初期化することで反映されます。

カスタマイズ方法

プロフィール・SNS設定など

管理画面の「外観 ＞ カスタマイズ ＞ トップページ」から編集画面に移動し、テキストボックス内の文章を編集することで各項目の内容を変更できます。各項目の名称（Gallery、Novelなど）も自由に変更できるので、サイトの雰囲気や用途に合わせてお好みの名称にしてください。

セクションの追加・削除

チェックボックスにチェックを入れることでセクションを3個まで増やすことができます。追加したセクションは「フリーテキスト型」「画像ギャラリー型」「小説リスト型」から選択可能。カテゴリー（スラッグ）を設定することで、作品をジャンルやカップリングごとに分けることもできます。

背景色・フォント設定

トップページのフォントは管理画面の「外観 ＞ エディター ＞ スタイル」から変更できます。single.html の背景色はトップページと連想していないため、フォントと同じく「スタイル」から変更してください。テーマカラーの背景色と合わせたい場合は以下のカラーコードに設定してください。

グレー【#f4f6f8】 ブルー【#f0f4f8】 ピンク【#fdf4f5】 グリーン【#f2f7f4】 パープル【#f6f4f8】

便利なプラグイン

サンプルサイトの作成時に使用させていただいたWordPressのプラグインです。

WP File Manager WordPressの編集画面でファイルのアップロードや管理ができます。
SEO Simple Pack 簡単な操作でOGP（リンクカード）などの設定ができます。
Reset Customizer 「カスタマイズ」で行った編集をリセットできます。

document.addEventListener('DOMContentLoaded', function() {
    
    /* 1. カードのスクロールフェードイン制御 */
    const cards = document.querySelectorAll('.fade-card');
    const observerOptions = {
        root: null,
        rootMargin: '0px 0px -30px 0px',
        threshold: 0.05
    };

    const observer = new IntersectionObserver((entries, observer) => {
        entries.forEach((entry, index) => {
            if (entry.isIntersecting) {
                setTimeout(() => {
                    entry.target.classList.add('is-visible');
                }, index * 80);
                observer.unobserve(entry.target);
            }
        });
    }, observerOptions);

    cards.forEach(card => {
        observer.observe(card);
    });

    /* 2. GALLERYモーダル表示制御 */
    const modal = document.getElementById('imageModal');
    const modalImg = document.getElementById('modalImg');
    const modalTitle = document.getElementById('modalTitle');
    const modalDesc = document.getElementById('modalDesc');
    const modalCloseBtn = document.getElementById('modalCloseBtn');
    const openBtns = document.querySelectorAll('.js-modal-open');

    openBtns.forEach(btn => {
        btn.addEventListener('click', function() {
            const imgSrc = this.getAttribute('data-img');
            const title = this.getAttribute('data-title');
            const desc = this.getAttribute('data-desc');

            modalImg.src = imgSrc;
            modalTitle.textContent = title;
            modalDesc.textContent = desc;

            modal.classList.add('is-active');
            document.body.style.overflow = 'hidden';
        });
    });

    function closeModal() {
        modal.classList.remove('is-active');
        document.body.style.overflow = '';
    }

    modalCloseBtn.addEventListener('click', closeModal);

    modal.addEventListener('click', function(e) {
        if (e.target === modal) {
            closeModal();
        }
    });

    document.addEventListener('keydown', function(e) {
        if (e.key === 'Escape' && modal.classList.contains('is-active')) {
            closeModal();
        }
    });

    /* 3. GALLERY「もっと見る」ボタン制御 */
    const loadMoreBtn = document.getElementById('loadMoreBtn');
    const galleryStep = <?php echo (int)$gallery_num; ?>;
    
    if (loadMoreBtn) {
        loadMoreBtn.addEventListener('click', function() {
            const hiddenItems = document.querySelectorAll('.js-gallery-item.is-hidden');
            
            for (let i = 0; i < galleryStep && i < hiddenItems.length; i++) {
                hiddenItems[i].classList.remove('is-hidden');
            }

            if (document.querySelectorAll('.js-gallery-item.is-hidden').length === 0) {
                loadMoreBtn.parentElement.style.display = 'none';
            }
        });
    }

    // --------------------------------------------------
    $wp_customize->add_setting( 'show_novel', array( 'default' => true, 'sanitize_callback' => 'wp_validate_boolean' ) );
    $wp_customize->add_control( 'show_novel', array( 'label' => 'Novelを表示する', 'type' => 'checkbox', 'section' => 'top_page_options' ) );

    $wp_customize->add_setting( 'novel_title', array( 'default' => 'Novel', 'sanitize_callback' => 'sanitize_text_field' ) );
    $wp_customize->add_control( 'novel_title', array( 'label' => 'Novel：セクション名', 'type' => 'text', 'section' => 'top_page_options' ) );

    $wp_customize->add_setting( 'novel_cat_slug', array( 'default' => 'novel', 'sanitize_callback' => 'sanitize_text_field' ) );
    $wp_customize->add_control( 'novel_cat_slug', array( 'label' => 'Novel：表示するカテゴリー（スラッグ）', 'type' => 'text', 'section' => 'top_page_options' ) );

    $wp_customize->add_setting( 'novel_desc', array( 'default' => '', 'sanitize_callback' => 'sanitize_text_field' ) );
    $wp_customize->add_control( 'novel_desc', array( 'label' => 'Novel：補足テキスト（空欄でデフォルト表示）', 'type' => 'text', 'section' => 'top_page_options' ) );

    $wp_customize->add_setting( 'novel_num', array( 'default' => 5, 'sanitize_callback' => 'absint' ) );
    $wp_customize->add_control( 'novel_num', array( 'label' => 'Novel：初期表示件数', 'type' => 'number', 'section' => 'top_page_options', 'input_attrs' => array('min' => 1) ) );

    // --------------------------------------------------
    // 5. 追加セクション (1〜3枠)
    // --------------------------------------------------
    for ( $i = 1; $i <= 3; $i++ ) {
        $wp_customize->add_setting( "show_extra{$i}", array( 'default' => false, 'sanitize_callback' => 'wp_validate_boolean' ) );
        $wp_customize->add_control( "show_extra{$i}", array( 'label' => "【追加】セクション{$i}を表示する", 'type' => 'checkbox', 'section' => 'top_page_options' ) );

        $wp_customize->add_setting( "extra{$i}_title", array( 'default' => "Extra {$i}", 'sanitize_callback' => 'sanitize_text_field' ) );
        $wp_customize->add_control( "extra{$i}_title", array( 'label' => "追加{$i}：セクション名", 'type' => 'text', 'section' => 'top_page_options' ) );

        // タイプ選択（About / Gallery / Novel）
        $wp_customize->add_setting( "extra{$i}_type", array( 'default' => 'gallery', 'sanitize_callback' => 'sanitize_text_field' ) );
        $wp_customize->add_control( "extra{$i}_type", array(
            'label'   => "追加{$i}：セクションのタイプ",
            'section' => 'top_page_options',
            'type'    => 'select',
            'choices' => array(
                'about'   => 'フリーテキスト型 (Aboutと同機能)',
                'gallery' => '画像ギャラリー型 (Galleryと同機能)',
                'novel'   => '小説リスト型 (Novelと同機能)',
            ),
        ) );

        $wp_customize->add_setting( "extra{$i}_cat_slug", array( 'default' => '', 'sanitize_callback' => 'sanitize_text_field' ) );
        $wp_customize->add_control( "extra{$i}_cat_slug", array( 'label' => "追加{$i}：カテゴリー（スラッグ※ギャラリー/小説型のみ）", 'type' => 'text', 'section' => 'top_page_options' ) );

        $wp_customize->add_setting( "extra{$i}_desc", array( 'default' => '', 'sanitize_callback' => 'sanitize_textarea_field' ) );
        $wp_customize->add_control( "extra{$i}_desc", array( 'label' => "追加{$i}：補足テキスト/文章本文", 'type' => 'textarea', 'section' => 'top_page_options' ) );

        $wp_customize->add_setting( "extra{$i}_num", array( 'default' => 10, 'sanitize_callback' => 'absint' ) );
        $wp_customize->add_control( "extra{$i}_num", array( 'label' => "追加{$i}：初期表示件数（※ギャラリー/小説型のみ）", 'type' => 'number', 'section' => 'top_page_options' ) );
    }

    // --------------------------------------------------
    // 6. Profile セクション設定
    // --------------------------------------------------
    $wp_customize->add_setting( 'show_profile', array( 'default' => true, 'sanitize_callback' => 'wp_validate_boolean' ) );
    $wp_customize->add_control( 'show_profile', array( 'label' => 'Profileを表示する', 'type' => 'checkbox', 'section' => 'top_page_options' ) );

    $wp_customize->add_setting( 'profile_title', array( 'default' => 'Profile', 'sanitize_callback' => 'sanitize_text_field' ) );
    $wp_customize->add_control( 'profile_title', array( 'label' => 'Profile：セクション名', 'type' => 'text', 'section' => 'top_page_options' ) );

    $wp_customize->add_setting( 'profile_icon', array( 'default' => '', 'sanitize_callback' => 'esc_url_raw' ) );
    $wp_customize->add_control( new WP_Customize_Image_Control( $wp_customize, 'profile_icon', array(
        'label'    => 'Profile：アイコン画像',
        'section'  => 'top_page_options',
    ) ) );

    $wp_customize->add_setting( 'profile_name', array( 'default' => 'お名前', 'sanitize_callback' => 'sanitize_text_field' ) );
    $wp_customize->add_control( 'profile_name', array( 'label' => 'Profile：名前', 'type' => 'text', 'section' => 'top_page_options' ) );

    $wp_customize->add_setting( 'profile_bio', array( 'default' => 'ここにプロフィールを書いてください。', 'sanitize_callback' => 'sanitize_textarea_field' ) );
    $wp_customize->add_control( 'profile_bio', array( 'label' => 'Profile：自己紹介文', 'type' => 'textarea', 'section' => 'top_page_options' ) );

    // SNS 枠（最大3つ設定可能）
    for ( $i = 1; $i <= 3; $i++ ) {
        $default_name = ($i === 1) ? 'X (旧Twitter)' : (($i === 2) ? 'pixiv' : '');
        $default_url  = ($i === 1) ? 'https://x.com/' : (($i === 2) ? 'https://pixiv.net/' : '');

        $wp_customize->add_setting( "sns_name_{$i}", array(
            'default'           => $default_name,
            'sanitize_callback' => 'sanitize_text_field',
        ) );
        $wp_customize->add_control( "sns_name_{$i}", array(
            'label'   => "SNS {$i}：ラベル名称",
            'type'    => 'text',
            'section' => 'top_page_options',
        ) );

        $wp_customize->add_setting( "sns_url_{$i}", array(
            'default'           => $default_url,
            'sanitize_callback' => 'esc_url_raw',
        ) );
        $wp_customize->add_control( "sns_url_{$i}", array(
            'label'   => "SNS {$i}：URL",
            'type'    => 'url',
            'section' => 'top_page_options',
        ) );
    }
}
