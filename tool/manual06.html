概要とライセンス・動作条件

本カスタマイズコードは、WordPress公式ブロックテーマ「Twenty Twenty-Five」上で、ポートフォリオ（ギャラリー）機能および小説テキスト投稿機能を実装するためのテンプレートです。

注意: 本コードはWordPress内のGUIツール（ブロックエディターのみの設定）では動作しない処理を含みます。ファイルの配置や軽微なコード編集が行える経験者向けのカスタマイズとなります。

動作前提条件

  • WordPressバージョン: 6.0 以上推奨 (検証: 7.1.3)
  • 対応テーマ: Twenty Twenty-Five (検証: 1.5)
  • 推奨サーバー環境: PHP 7.4 / 8.0 以上 (検証: 8.5.x)

このカスタマイズコードの主な機能

1. Gallery（イラストギャラリー）

  • サムネイル自動取得: 記事を「イラスト」カテゴリで投稿すると、アイキャッチまたは記事内画像を自動抽出。
  • モーダル拡大表示: 画像タップでふわっと拡大。タイトルと画像は中央、説明文は左寄せで綺麗に表示。
  • 「もっと見る」表示: 初期15件を表示し、ボタンタップで段階的に追加読み込み。

2. Novel（小説・テキスト投稿）

  • 冒頭の自動プレビュー: 「小説」カテゴリ投稿からタイトルと本文冒頭（抜粋）をすっきり一覧表示。
  • 「もっと見る」表示: 初期5件を表示し、以降はボタンで展開。
  • フォントを明朝体に（single.html）: 記事ページに明朝体を適用し、文章を美しく見せます。

導入手順（詳しいガイド）

STEP 1

投稿カテゴリーを作成する

WordPress管理画面の 「投稿」＞「カテゴリー」 で以下の2つを作成します。

• イラスト用 ➔ 名前: イラスト / スラッグ: illust
• 小説用 ➔ 名前: 小説 / スラッグ: novel

※スラッグ名を変更する場合はコード側の category_name も書き換えてください。

STEP 2

ファイルをテーマフォルダ内に配置する

サーバーのファイルマネージャーまたはFTPソフト（またはプラグイン「WP File Manager」）を使い、以下の通り配置します。

// ① トップページ用ファイルの新規作成配置
/wp-content/themes/twentytwentyfive/front-page.php
// ② 小説個別ページ用ファイル末尾に追記
/wp-content/themes/twentytwentyfive/templates/single.html
STEP 3

固定ページを作成しトップに指定する

  1. 管理画面の 「固定ページ」＞「固定ページを追加」 を選択。
  2. タイトルに「トップ」と入力し、本文は空のまま公開します。
  3. 管理画面の 「設定」＞「表示設定」 へ移動。
  4. 「ホームページの表示」で 「固定ページ」 を選択し、「ホームページ:」のドロップダウンで作成した「トップ」を選択して保存します。
STEP 4

表示確認とトラブルシューティング

サイトトップを開き、表示を確認します。変更が反映されない場合は以下を確認してください。

💡 エディターのカスタマイズリセット: 過去に「外観 ＞ エディター」で「個別投稿」などを保存したことがある場合、DBデータが優先されます。「外観 ＞ エディター ＞ テンプレート ＞ 個別投稿」の右上メニューから「カスタマイズをリセット」を実行してください。

カスタマイズ方法

プロフィール・SNS設定

front-page.php 内の <section id="profile"> 部分にある名前、テキスト、SNSリンク（X, pixiv等）をご自身のものに変更してください。

サムネイル縦横比の調整

標準は3:4比率です。変更したい場合は aspect-ratio: 3 / 4; の数値を変更します。
・ポスター感 (A判): 1 / 1.414
・スマホ縦長: 9 / 16

背景色・フォント設定

基本デザインは管理画面の「外観 ＞ エディター ＞ スタイル」から調整可能ですが、front-page.php の背景色や single.html のフォント（明朝体）はCSSで固定されているため、コードを直接変更してください。

タイトル・OGP・ファビコン

<head> 内に直接コードを書くとWPの機能と競合してしまう可能性があります。コードの追加はせず、WPの標準機能やプラグイン（SEO Simple Pack 等）に委ねることを推奨します。

<script>
document.addEventListener('DOMContentLoaded', function() {
    
    /* 1. カードのスクロールフェードイン制御 */
    const cards = document.querySelectorAll('.fade-card');
    const observerOptions = {
        root: null,
        rootMargin: '0px 0px -30px 0px',
        threshold: 0.05
    };

    const observer = new IntersectionObserver((entries, observer) => {
        entries.forEach((entry, index) => {
            if (entry.isIntersecting) {
                setTimeout(() => {
                    entry.target.classList.add('is-visible');
                }, index * 80);
                observer.unobserve(entry.target);
            }
        });
    }, observerOptions);

    cards.forEach(card => {
        observer.observe(card);
    });

    /* 2. GALLERYモーダル表示制御 */
    const modal = document.getElementById('imageModal');
    const modalImg = document.getElementById('modalImg');
    const modalTitle = document.getElementById('modalTitle');
    const modalDesc = document.getElementById('modalDesc');
    const modalCloseBtn = document.getElementById('modalCloseBtn');
    const openBtns = document.querySelectorAll('.js-modal-open');

    openBtns.forEach(btn => {
        btn.addEventListener('click', function() {
            const imgSrc = this.getAttribute('data-img');
            const title = this.getAttribute('data-title');
            const desc = this.getAttribute('data-desc');

            modalImg.src = imgSrc;
            modalTitle.textContent = title;
            modalDesc.textContent = desc;

            modal.classList.add('is-active');
            document.body.style.overflow = 'hidden';
        });
    });

    function closeModal() {
        modal.classList.remove('is-active');
        document.body.style.overflow = '';
    }

    modalCloseBtn.addEventListener('click', closeModal);

    modal.addEventListener('click', function(e) {
        if (e.target === modal) {
            closeModal();
        }
    });

    document.addEventListener('keydown', function(e) {
        if (e.key === 'Escape' && modal.classList.contains('is-active')) {
            closeModal();
        }
    });

    /* 3. GALLERY「もっと見る」ボタン制御（15件単位） */
    const loadMoreBtn = document.getElementById('loadMoreBtn');
    if (loadMoreBtn) {
        loadMoreBtn.addEventListener('click', function() {
            const hiddenItems = document.querySelectorAll('.js-gallery-item.is-hidden');
            
            for (let i = 0; i < 15 && i < hiddenItems.length; i++) {
                hiddenItems[i].classList.remove('is-hidden');
            }

            if (document.querySelectorAll('.js-gallery-item.is-hidden').length === 0) {
                loadMoreBtn.parentElement.style.display = 'none';
            }
        });
    }

    /* 4. NOVEL「もっと見る」ボタン制御（5件単位） */
    const loadMoreNovelBtn = document.getElementById('loadMoreNovelBtn');
    if (loadMoreNovelBtn) {
        loadMoreNovelBtn.addEventListener('click', function() {
            const hiddenNovelItems = document.querySelectorAll('.js-novel-item.is-hidden');
            
            for (let i = 0; i < 5 && i < hiddenNovelItems.length; i++) {
                hiddenNovelItems[i].classList.remove('is-hidden');
            }

            if (document.querySelectorAll('.js-novel-item.is-hidden').length === 0) {
                loadMoreNovelBtn.parentElement.style.display = 'none';
            }
        });
    }

});
</script>
