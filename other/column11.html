はじめに

「二次創作や夢小説を自分のサイトで公開したい！」
「でも、名前変換やパスワード制限、検索よけってどうやればいいの？」

そんな方向けに、HTMLサイトに「検索よけ」や「パスワード」を設定する方法と、「夢小説機能」の導入方法をわかりやすく解説します！

二次創作サイトで必須の「検索よけ（SEO対策）」

二次創作サイトを運営する上で重要なのが、Googleなどの検索エンジンにサイトを載せない設定です。関係者や二次創作が苦手な人の目に触れないよう、検索よけを設定しておきましょう。

❓ 検索よけは絶対にするべき？

版権元が二次創作を許可している場合もあるため、「二次創作サイトであれば必ずしも検索よけをしなければならない」というわけではありません。

ただし、センシティブなコンテンツを含む場合は二次創作以前のマナーとして設定しておきましょう！

メタタグによる検索除外（noindex）

検索よけをしたいHTMLファイルの <head> 〜 </head> の間（<title> のすぐ下など）に、以下のコードを記述します。

すべてのページに設定する方法のほか、「注意書きが記述してあるトップページだけ設定しない」という方法もあります。

📋 検索よけメタタグ 
<!-- 検索エンジンからのインデックス（登録）と巡回を拒否するタグ -->
  <meta name="robots" content="noindex,nofollow">
💡 設定値の意味
・noindex：検索結果にこのページを表示させない指示
・nofollow：検索エンジンのロボットがページ内のリンクを辿らないようにする指示
この1行を入れておくことで、大半の検索エンジンからのアクセスを防ぐことができます。

簡易パスワードを設置する方法

サイトの入口や子ページに閲覧制限を設けたい場合、JavaScriptを使った簡易パスワード制限が手軽です。

これを設置しておくことで、ページを開いたときにパスワード入力用のダイアログが表示されます。

📷 実際に表示されるダイアログ

ページ読み込み時にパスワードを求めるコード

制限をかけたいページの <head> 直下に以下のコードを記述します。

📋 簡易パスワード制限コード 
<script>
  // 正しいパスワードを設定（例：1234）
  const CORRECT_PASS = "1234";

  // パスワード入力画面を出す
  const userInput = prompt("パスワードを入力してください（ヒント：公式発売日4桁）");

  // 入力値の判定
  if (userInput !== CORRECT_PASS) {
    alert("パスワードが違います。トップページに戻ります。");
    window.location.href = "index.html"; // 正しくない場合の移動先
  }
</script>
⚠️ 注意点（ワンポイント解説）
JavaScriptのパスワード制限は、ブラウザの「ページのソースを表示」で見破ることができる簡易的な仕組みです。強固なパスワードを設けたい場合は、サーバー側の設定（.htaccessなどによるBasic認証）を検討するのがおすすめです。

コピペで使える！名前変換機能

名前の入力フォームを設置し、読者が入力した名前を本文に反映させる機能です。入力した名前はブラウザに保存されるため、ページを移動しても名前が保持されます。

📷 当サイトで配布している小説用ページ「Blue Novel」のカード内に入力フォームを設置した例

1. スクリプトを配置する

まず、以下のスクリプトを script.js というファイル名で保存します。その後、すべてのHTMLファイルの </body> 直前に <script src="script.js"></script> のタグを挿入して読み込ませます。

📋 script.js 
// 名前をローカルストレージに保存する関数
function saveName() {
  const lastName = document.getElementById('input-lastname').value;
  const firstName = document.getElementById('input-firstname').value;

  localStorage.setItem('dream_lastname', lastName);
  localStorage.setItem('dream_firstname', firstName);

  alert('名前を保存しました！');
}

// ページ読み込み時に本文中の名前を置換し、フォーム値も復元する処理
window.addEventListener('DOMContentLoaded', () => {
  const savedLast = localStorage.getItem('dream_lastname') || 'デフォルト苗字';
  const savedFirst = localStorage.getItem('dream_firstname') || 'デフォルト名前';

  // 本文中の苗字・名前を置換
  document.querySelectorAll('.dream-last').forEach(el => el.textContent = savedLast);
  document.querySelectorAll('.dream-first').forEach(el => el.textContent = savedFirst);

  // ページ内に入力フォームがあれば、現在の設定値を自動セット
  const inputLast = document.getElementById('input-lastname');
  const inputFirst = document.getElementById('input-firstname');
  if (inputLast) inputLast.value = savedLast;
  if (inputFirst) inputFirst.value = savedFirst;
});
💡 一体型のコードの場合
HTML/CSS/JavaScript が一体化したコード内に上記のコードを追加したい場合は、上記のコードを <script> </script> で挟んで、本体のコードの最下部にある </body> の直前に張り付けてください🐾

2. 名前入力フォームを設置する

名前入力フォームは、設置したい場所（小説一覧ページや、本文の上部など）に合わせて下記のコードを設置します。

A作品一覧ページに入力フォームを設置する場合

作品一覧ページで名前を設定してもらい、すべての小説に反映させるパターンです。

📋 名前入力フォーム 
<!-- 名前入力フォーム -->
<div class="name-form">
  <h3>名前設定</h3>
  <div class="form-group">
    <label>苗字: <input type="text" id="input-lastname" value="デフォルト苗字"></label>
  </div>
  <div class="form-group">
    <label>名前: <input type="text" id="input-firstname" value="デフォルト名前"></label>
  </div>
  <button onclick="saveName()" class="save-btn">この名前で保存する</button>
</div>

B小説内（各ページ）に入力フォームを設置する場合

小説の冒頭や途中に入力フォームを置きたい場合のパターンです。本文とフォームを同一ページに設置し、保存ボタンを押した瞬間に再読み込みして置き換えます。

📋 名前入力フォーム 
<!-- 名前入力フォーム -->
<div class="name-form">
  <p class="form-title">名前設定</p>
  <div class="form-group">
    <label>苗字: <input type="text" id="input-lastname" value="デフォルト苗字"></label>
  </div>
  <div class="form-group">
    <label>名前: <input type="text" id="input-firstname" value="デフォルト名前"></label>
  </div>
  <button onclick="saveName(); location.reload();" class="save-btn">この名前で保存する</button>
</div>
💡 本文の途中で名前を入力させる小技
Bの方法では『登場人物の「あなたのお名前は？」という質問のあとに入力フォームを設置する』など、ゲームのような構成にすることも可能です🐾

3. 入力した名前を小説に反映させる

名前を反映させたい部分に dream-first や dream-last のタグを挿入することで、保存された名前が小説ページに反映されます。

📋 本文ページ 
<p>
  「おい、<span class="dream-first">デフォルト名前</span>。いつまで寝ているんだ」<br>
  <span class="dream-last">デフォルト苗字</span>は呆れた顔でこちらを見つめていた。
</p>

入力フォームを可愛く変身させるCSS

デフォルトの入力枠やボタンは素朴になデザインになっていますが、以下のCSSを組み込むことで、角を丸く柔らかい印象にし、可愛いフォームに変身させることができます。

ご自身のサイトのデザインに合わせて丸みや色を調整してみてくださいね🐾

📷 下記のコードをそのまま使用するとこのようなデザインになります

<head> タグ内（<style> ～ </style> の間）に書くか、外部CSSファイル（style.css 等）に追記してご使用ください。

📋 style.css 
/* --- フォーム全体のデザイン --- */
.name-form {
  background-color: #fffaf0; /* ふんわりとした淡い背景色 */
  border: 2px dashed #f4a7b9; /* くすみピンクの破線フレーム */
  border-radius: 12px;        /* 全体の角を丸く */
  padding: 20px;
  max-width: 360px;
  margin: 20px auto;
  text-align: center;
  box-shadow: 0 4px 6px rgba(0, 0, 0, 0.05); /* うっすら影をつける */
}

/* --- 入力欄（テキストボックス）のデザイン --- */
.name-form input[type="text"] {
  border: 1px solid #dcdcdc;
  border-radius: 20px;       /* 入力欄の角を大きく丸める */
  padding: 6px 14px;
  font-size: 14px;
  outline: none;
  transition: all 0.3s;
}

/* 入力欄をクリック（フォーカス）したときの色変化 */
.name-form input[type="text"]:focus {
  border-color: #f4a7b9;
  box-shadow: 0 0 5px rgba(244, 167, 185, 0.5);
}

/* --- 確定（保存）ボタンのデザイン --- */
.save-btn {
  background-color: #f4a7b9; /* メインカラー（くすみピンク） */
  color: #ffffff;            /* 文字色 */
  border: none;
  border-radius: 20px;       /* ボタンの角を丸く */
  padding: 8px 24px;
  font-size: 14px;
  font-weight: bold;
  cursor: pointer;
  transition: background-color 0.3s;
  margin-top: 10px;
}

/* ボタンにマウスを乗せたときの変化 */
.save-btn:hover {
  background-color: #e0869b; /* 少し濃いピンクに変化 */
}

/* ラベル周りの余白調整 */
.form-group {
  margin-bottom: 10px;
}
💡 カスタマイズのワンポイント解説
・角を丸くする (border-radius)：値（px）を大きくするほど、角が丸くなります。20px前後にするとコロンとした丸ボタンやカプセル型の入力欄になります。
・カラーの変更：#f4a7b9（ピンク）の部分を、サイトの世界観に合わせて好きな色コード（和風なら抹茶色、クール系なら水色やグレーなど）に変更するだけで一気に雰囲気が変わります。

安心・安全にサイトを運営するためのチェックリスト

サイトを公開する前に、以下の項目が確認できているかチェックしてみましょう。

  • 必要なページの <head> 内に <meta name="robots" content="noindex,nofollow"> が入っているか
  • サイトの入口に「二次創作や年齢制限つきのコンテンツを含むこと」等の注意書きを記載しているか
  • 作品一覧で名前を入力した後、別ページの小説でも正しく名前が変わるか動作確認したか
  • パスワードを入力しなかった場合・間違えた場合に正しく弾かれるか確認したか
