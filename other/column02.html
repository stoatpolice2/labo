はじめに

「自分のサイトを作ってみたいけれど、有料サーバーを借りるのはハードルが高い…」とお悩みの方に、管理人が実際に利用している無料レンタルサーバーの「FC2ホームページ」「Wix」「GitHub Pages」の3つをご紹介します🐾

共通のおすすめポイント

  • 完全無料で始められる！
  • 広告が少ない（または全くない）！
  • 特別なソフト（FTPソフトや専用エディタ）が必要ない！

おすすめ比較表

各サービスの特徴やおすすめの用途をまとめました。

サービス こんな人におすすめ！ 容量目安 アダルト 広告
FC2ホームページ WEB漫画・イラストメイン / 手軽に始めたい 1GB 別鯖で可 控えめ
Wix ノーコードでおしゃれにしたい / 成人向けも扱いたい 500MB ○ 地味
GitHub Pages 完全広告なしがいい / HTML・CSSが書ける 1GB × なし
💡 商用利用・同人通販についての注意点
いずれのサービスも基本的な同人通販（BOOTHなど）へのリンク掲載は可能ですが、本格的な商用ECサイト運用には制限がある場合があるため、事前に各利用規約をご確認ください。

1. FC2ホームページ

〜手軽にイラスト・漫画サイトを作りたい方へ〜

おすすめポイント

  • 広告が控えめ！： PC表示ではなんと広告なし。モバイル表示時もページの一番下にひっそり出るだけなので、作品の雰囲気を邪魔しません！
  • 無料枠でたっぷり1GB使える！： 容量が1GBあるため、イラスト画像やWEB漫画のページ数が増えても安心です。
  • テンプレートが豊富！： 同サービス内で使いやすいテンプレートが配布されているため、外部サイトから探してくる手間がありません。
  • 管理画面だけで編集OK！： 管理画面の「ファイルマネージャー」を使えば、ブラウザ上で直感的にファイルの編集やアップロードが完了します。
  • 創作サイトに嬉しい「アルバムメーカー」機能！： Web漫画やイラストの公開に特化した機能が標準装備されているので、作品発表の場として最適です。

いまいちなポイント

  • 長期間更新がないと広告が増える： 一定期間（約3ヶ月〜半年ほど）サイトの更新がないと、自動的に大きめの広告が表示されるようになります。定期的なログインや更新を心がけましょう！
  • 成人向けコンテンツは通常サーバーでは不可！： R-18作品などを掲載したい場合は、FC2が提供している専用のアダルトサーバー（別枠）を利用する必要があるので注意してください。

2. Wix（ウィックス）

〜コード不要！ノーコードでおしゃれなサイトを作りたい方へ〜

おすすめポイント

  • 広告のデザインが地味で目立たない！： 上部に小さく表示される程度で、サイトのデザインを崩しにくい設計になっています。
  • マウス操作だけで動くサイトが作れる！： 専用のGUI（視覚的な編集ツール）を使うため、HTML/CSSなどのコードが書けなくても、プロが作ったような動きのあるおしゃれなサイトが作れます。テンプレートも超豊富！
  • スマホ観覧時の詳細設定もできる！： スマホからアクセスした際の「ウェルカム画面」を設定したり、「ステータスバー（時計や電池残量が表示される部分）」の色を簡単に変更できます！
  • オールインワンの機能性！： ブログ、メールフォーム、アクセス解析など、サイト運営に必要な機能が最初から全部揃っています。
  • アダルトコンテンツOK！： 無料サーバーの中では珍しく、成人向けコンテンツの掲載が許可されています。

いまいちなポイント

  • 無料枠の容量は500MBまで： FC2に比べると容量が少なめなので、高画質な画像を大量に載せる場合は画像を軽量化してアップロードする工夫が必要です。
  • 自分でコードを書きたい人には不向き： 自由度の高いビジュアル編集ができる反面、直接HTML/CSSをいじりたい経験者の方には「かゆいところに手が届かない」と感じる部分があるかもしれません。

3. GitHub Pages（ギットハブページズ）

〜広告完全なし！コードが書ける本格派・作品保管庫に〜

「GitHub（ギットハブ）」とは？
世界中のエンジニアがプログラムやコードを保存・共有するために使っているサービスです。このGitHubが提供しているWebサイトホスティング機能が「GitHub Pages」です。

おすすめポイント

  • 完全に広告なし！： 無料にもかかわらず、一切の広告が表示されません。（※今ご覧になっているこのページもGitHub Pagesで公開しています！）
  • 容量もしっかり1GB使える！： 広告なしで1GB（推奨上限）のスペースが使えるのは非常に強力です。
  • ドラッグ＆ドロップで簡単アップロード！： ドロップエリアにファイルを移動するだけでアップロードが完了。FTPソフトは必要ありません！
  • スマホからでも編集できる！：Web上の編集画面で直接コードを書くことも可能です。スマホからでも利用できるので、PCを使えないときでもササっとHTMLを編集できます！
  • 履歴が残るので失敗してもすぐ戻せる！： 「編集したらレイアウトが崩れてしまった…」という時でも、変更前の状態に一瞬で復元できるのが大きな強みです。

いまいちなポイント

  • 成人向けコンテンツは禁止！： 規約によりアダルトコンテンツの掲載はできません。
  • UIが英語中心： 管理画面（GitHub）が日本語化されていないため、外国語に抵抗がある方には難しく感じるかもしれません。（※サイト内の文章自体は日本語でも作成できます！）
  • テンプレートや便利ツールはない： テンプレートの配布はないため、自分でコードを書くか外部サイトからテンプレートを借りてくる必要があります。また、ブログやメールフォームといった便利ツールもありません。

まとめ

それぞれのサーバーに向いている人をまとめました🐾

  • イラスト・漫画をサクッと公開したい ➔ FC2ホームページ
  • コードを書かずにおしゃれなサイトを作りたい・成人向け作品を扱いたい ➔ Wix
  • 広告ゼロにこだわりたい・コードを書いて自由なサイトを作りたい ➔ GitHub Pages

ご自身の制作スタイルや作品内容、掲載したいコンテンツに合わせて、ぜひ自分にぴったりのサーバーを試してみてくださいね！
