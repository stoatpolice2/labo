Pattern 01

シングルカラム・スリム（最適文字数・読み幅制限）

日本語のWEB読書において最も疲れにくいとされる「1行35〜40文字前後 (`max-width: 38em` 前後)」の幅に制限した標準レイアウトです。Mediumやnote、電子書籍リーダーでも標準的に採用されています。

各パターンの「コードを表示」ボタンで、実装に必要なHTML/CSSコードを取得できます。

行間調整プレビュー:

見本章タイトル：レイアウトの確認

これはデザインやレイアウトを確認するためのダミー文章です。実際の本文が入った際の文字の並びや、行間の開き具合、全体の読みやすさをテストするために配置されています。

文章の長さや改行の位置を変えることで、余白のバランスや画面上での見映えをシミュレーションできます。フォントの変更やサイズ調整の際も、この見本テキストを参考に確認してください。

「ここに会話文や強調したいセリフが入る場合の表示見本です。」

このように、段落ごとに適度な行間を確保することで、長文であっても読者が視線をスムーズに移動させやすくなります。目的のコンテンツに合わせて自由に差し替えてご活用ください。 

<!-- HTML -->
<article class="max-w-[38em] mx-auto text-base leading-[1.85] space-y-6">
  <h3 class="text-xl font-bold border-b pb-2">見本章タイトル：レイアウトの確認</h3>
  <p>これはデザインやレイアウトを確認するためのダミー文章です...</p>
</article>

<!-- CSSのポイント -->
/* max-width: 35em〜40em（日本語で約35〜40文字/行）に設定 */
/* line-height: 1.8 〜 1.9 が長文読了に最も適しています */
Pattern 02

ヒーローセクション ＋ ドロップキャップ

作品の扉ページや短編小説・コラムの冒頭に最適。大きなタイトル・サブタイトルと、物語の先頭一文字を巨大化させるドロップキャップ（`::first-letter`）で雑誌のような上質な世界観を作り出します。

Sample Article Layout

見本用の記事大タイトル

― サブタイトルの表示位置とデザイン確認用のダミーテキストです ―

執筆者: サンプル太郎 • 読了目安: 約3分

文頭の文字を大きく強調表示するドロップキャップの表示見本です。ここには見本用の文章が入ります。先頭の一文字が印象的に大きくデザインされるため、雑誌の冒頭や物語の始まりのような上質な雰囲気を演出できます。

「２行目以降の段落も、全体のスタイルに合わせて綺麗に流れるか確認します」

文字のサイズや行間、フォントの種類を変更した際にも、頭文字のデザインが崩れずに保たれるかテストするためのダミー文章です。 

<!-- ドロップキャップ用CSS -->
<style>
.drop-cap::first-letter {
  font-size: 3.5em;
  float: left;
  line-height: 0.85;
  margin-right: 0.15em;
  font-weight: bold;
  color: #8c2d19; /* アクセントカラー */
}
</style>

<!-- HTML構造 -->
<p class="drop-cap">文頭の文字を大きく強調表示する...</p>
Pattern 03

日本語縦書きレイアウト（縦中横対応）

CSSの `writing-mode: vertical-rl;` を使用した本格的な縦書き組版です。2桁の数字などを正しく直立させる「縦中横（`text-combine-upright`）」も組み込んでいます。右から左へと横スクロールして読み進めます。

縦書きの見本 第01章

　これは日本語の縦書き表示を確認するためのダミー文章です。右から左へと読み進める組版の確認に使用します。

　縦書き表示のなかで、半角数字の12月25日のように二桁の数字を横並びで綺麗に表示させる技術を「縦中横」と呼びます。

「このように会話文が入った場合のカッコの向きや、行間の開き具合も綺麗に整います」

　画面を右から左へスクロールしながら、和風Webサイトや小説コンテンツの表示イメージを確認してください。

　歴史もの、時代ものなどの和風の小説に雰囲気を持たせたり、背景色をクリーム色にすることで古書のようなデザインにするといった用途で使えます。

　パソコンからの観覧だと画面の横幅が広いので、設定によってはスクロールバーが出ていないかもしれません。

　この文章の下にスクロールバーが表示されない場合は、ウインドウを少し小さくしてみてください。

← 右から左へスクロールして読めます

<!-- 縦書き用CSS -->
<style>
.writing-vertical {
  writing-mode: vertical-rl;
  -webkit-writing-mode: vertical-rl;
  text-orientation: mixed;
}
/* 縦中横（2桁の数字などを縦書きの中で横並びにする） */
.tcy {
  text-combine-upright: all;
  -webkit-text-combine: horizontal;
}
</style>

<!-- HTML -->
<div class="writing-vertical h-[400px] overflow-x-auto">
  <h2>第<span class="tcy">01</span>章</h2>
  <p>これは日本語の縦書き表示を確認するための...</p>
</div>
Pattern 04

プルクオート ＆ 印象的フレーズの強調

長文の中で重要なセリフや名言、記事の結論などを視覚的に目立たせる演出です。読者が流し読みをしていても目を留めやすくなり、読書リズムにアクセントを与えます。

文章の途中で重要なメッセージや引用文を強調したい場合のレイアウト見本です。前後の文脈から際立たせることで読者の目を惹きつけます。

“

これはプルクオート（引用・強調枠）の見た目を確認するための見本テキストです。

— 引用元の出典や補足情報

引用ブロックの前後にはこのように通常の本文が続きます。枠線や背景色のバランスを確認できます。

「上下に境界線を配置した中央揃え強調フレーズの見本です」

スタイルの異なる2種類の強調デザインを用意することで、記事の雰囲気やコンテンツの意図に応じて使い分けることができます。 

<!-- プルクオート（左枠線付き） -->
<blockquote class="my-6 p-6 bg-paper-100 border-l-4 border-accent rounded-r-xl">
  <p class="text-lg font-bold text-accent">これはプルクオート（引用・強調枠）の...</p>
  <cite class="block text-right text-xs text-gray-500 mt-2">— 出典名など</cite>
</blockquote>

<!-- 中央強調フレーズ（上下線付き） -->
<div class="my-8 py-6 border-y border-paper-200 text-center">
  <p class="text-xl font-semibold">「上下に境界線を配置した...」</p>
</div>
Pattern 05

2カラム ＋ スティッキー目次（Sticky ToC）

長編小説の章一覧や、Webコラム・解説記事に最適なレイアウトです。画面左側の目次がスクロール追従（`position: sticky`）し、読者がいつでも現在位置を把握できます。

Contents

  • 1. 項目見出しその１
  • 2. 項目見出しその２
  • 3. 項目見出しその３

1. 項目見出しその１

ここはサイドバー固定目次と連動する本文エリアの見本テキストです。スクロールした際にも左側の目次エリアが画面に追従して固定表示されます。

2. 項目見出しその２

解説記事やドキュメント、長編記事などの構成で使いやすいレイアウトです。見出しデザインと本文の余白感を確認してください。

3. 項目見出しその３

各セクションへのスムーズスクロール動作や、モバイル表示時のレスポンシブなカラム落ち（1カラム化）の挙動もテストしていただけます。 

<!-- 親要素に flex / items-start を指定 -->
<div class="flex flex-col md:flex-row gap-8 items-start">
  <!-- スティッキー目次 (md:sticky md:top-24) -->
  <nav class="w-full md:w-56 md:sticky md:top-24 p-4 bg-paper-100">
    <h4>目次</h4>
    <ul>
      <li><a href="#sec1">1. 項目見出し</a></li>
    </ul>
  </nav>

  <!-- メイン本文 -->
  <div class="flex-1 space-y-8">
    <section id="sec1">...</section>
  </div>
</div>
Pattern 06

アコーディオン ＆ 脚注ポップアップ

作品内の専門用語の解説、作者あとがき、設定資料などを文章の流れを阻害せずに掲載するパターンです。クリック（タップ）で開閉できるアコーディオンや、ツールチップ型の脚注を活用します。

注釈付きテキストの表示見本です。本文中の気になる用語 ［※1: 見本用用語］ ホバー時に表示されるツールチップ形式の注釈見本テキストです。 の上にマウスを載せる（またはタップする）ことで、補足説明をポップアップ表示できます。

【補足エリア】クリックで開閉する見本枠です ▼

アコーディオンの中身に入る解説や補足文章の見本です。長文の注釈や「あとがき」「設定資料」などを、読者の操作で展開できるように収納しておけます。 

<!-- ピュアHTML5 アコーディオン (<details> / <summary>) -->
<details class="bg-paper-100 p-4 rounded-xl">
  <summary class="font-bold cursor-pointer">【補足エリア】クリックで開閉...</summary>
  <p class="mt-2 text-xs">アコーディオンの中身に入る解説のダミー文章...</p>
</details>
