Web画像レイアウト見本集

個人サイトで使える各種配置パターンのサンプルページです。

各パターンの「コードを表示」ボタンで、実装に必要なHTML/CSSコードを取得できます。


※ページ内に表示している画像はフリー素材をお借りしたものです。

Pattern 01

1. ベタ貼り（インライン / ブロック）

画像を縦に順番に並べる最もシンプルな配置です。作品解説や文章とセットで見せる場合に向いています。

作品タイトル：「青の記憶」 / 制作日：2026.01.10
作品タイトル：「静かな波」 / 制作日：2026.02.15 
<!-- HTML -->
<div class="block-gallery">
  <div class="item">
    <img src="image1.jpg" alt="作品01">
    <caption class="caption">作品タイトル：「ここにタイトルを入力」 / 制作日：2026.01.10</caption>
  </div>
</div>

<!-- CSS -->
.block-gallery .item { margin-bottom: 20px; }
.block-gallery .item img { width: 100%; border-radius: 4px; }
.block-gallery .item caption { display: block; margin-top: 6px; font-size: 0.85rem; color: #555; }
Pattern 02

2. グリッド配置（正方形トリミング）

サムネイルを整列させて並べる一覧性の高い配置です。ホバー時に少し拡大するアニメーションをつけています。

<!-- HTML -->
<div class="grid-gallery">
  <div class="item"><img src="image1.jpg" alt="Grid 1"></div>
</div>

<!-- CSS -->
.grid-gallery { display: grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 15px; }
.grid-gallery .item { aspect-ratio: 1 / 1; overflow: hidden; border-radius: 4px; background-color: #eee; }
.grid-gallery .item img { width: 100%; height: 100%; object-fit: cover; transition: transform 0.3s ease; }
.grid-gallery .item img:hover { transform: scale(1.05); }
Pattern 03

3. メイソンリー配置（レンガ状・縦横比保持）

縦長・横長などサイズの異なる画像をトリミングせず、隙間なく敷き詰めるレイアウトです。

<!-- HTML -->
<div class="masonry-gallery">
  <div class="item"><img src="image1.jpg" alt="縦長"></div>
</div>

<!-- CSS -->
.masonry-gallery { column-count: 3; column-gap: 15px; }
@media (max-width: 600px) { .masonry-gallery { column-count: 2; } }
.masonry-gallery .item { break-inside: avoid; margin-bottom: 15px; }
.masonry-gallery .item img { width: 100%; border-radius: 4px; }
Pattern 04

4. モーダル表示（クリックで大画像拡大）

サムネイルをクリックすると、画面全体が暗くなり大きな画像がオーバーレイ表示されます。

× 
<!-- HTML -->
<div class="modal-gallery">
  <img src="image1.jpg" alt="拡大画像" class="modal-trigger">
</div>
<div class="modal-overlay" id="modalOverlay">
  <span class="modal-close" id="modalClose">&times;</span>
  <img src="" alt="拡大表示" class="modal-content" id="modalImg">
</div>

<!-- JavaScript -->
const modalOverlay = document.getElementById('modalOverlay');
const modalImg = document.getElementById('modalImg');
document.querySelectorAll('.modal-trigger').forEach(img => {
  img.addEventListener('click', () => {
    modalImg.src = img.src;
    modalOverlay.classList.add('active');
  });
});
Pattern 05

5. スライドギャラリー（カルーセル）

左右のボタンで画像を1枚ずつ切り替えて展示します。省スペースで複数枚を見せるのに便利です。

<!-- HTML -->
<div class="slider-container">
  <div class="slider-track" id="sliderTrack">
    <div class="slider-slide"><img src="image1.jpg"></div>
    <div class="slider-slide"><img src="image2.jpg"></div>
  </div>
  <button class="slider-btn prev" id="sliderPrev">❮</button>
  <button class="slider-btn next" id="sliderNext">❯</button>
</div>
Pattern 06

6. ビフォーアフター比較（スライダー比較）

中央のバーを左右にドラッグ／移動することで、2枚の画像（例：線画と完成品）をインタラクティブに比較できます。

<!-- HTML -->
<div class="ba-container">
  <img class="ba-img" src="after.jpg" alt="After">
  <div class="ba-overlay-img" id="baOverlay">
    <img src="before.jpg" alt="Before">
  </div>
  <div class="ba-line" id="baLine"></div>
  <input type="range" min="0" max="100" value="50" class="ba-slider-input" id="baInput">
</div>
Pattern 07

7. アコーディオン展開（シリーズごとの折りたたみ）

見出しをクリックするとエリアが広がり、中の画像群が表示されます。ページ全体をスッキリ保ちたい場合に有効です。

📁 2026年制作 イラスト一覧（3枚） ▼
📁 落書き・ラフ集 ▼

<div class="accordion-item">
  <div class="accordion-header">📁 カテゴリ名 <span>▼</span></div>
  <div class="accordion-content">
